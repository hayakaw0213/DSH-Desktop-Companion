# DSH 桌面陪伴

Windows 桌面陪伴应用：Live2D 角色、好感度互动和桌面小工具，都放在一个客户端里。

## 下载

最新安装包见 Releases 页面。

- 文件名：`DSH桌面陪伴-Setup-1.0.1.exe`
- 大小：约 811 MB
- 系统：Windows 10 / 11（64 位）

## 安装

1. 下载安装包。
2. 双击运行；如提示「未知发布者」，点「更多信息 → 仍要运行」。
3. 按向导完成安装，首次启动会自动准备运行环境。

## 主要功能

- Live2D 桌面角色，多模型切换
- 好感度与投喂互动
- Galgame 风格界面
- 网易云音乐联动
- 电脑性能监控
- QQ 消息提醒

## 反馈

安装或使用中遇到问题，欢迎提 Issue，附上系统版本和日志更快定位。
